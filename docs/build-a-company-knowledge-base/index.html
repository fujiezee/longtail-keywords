企业知识库怎么搭建

企业知识库怎么搭建，先写清三件事：文件现在在哪，谁可以看，新人第一周会问哪十个问题。这三件没写下来就换系统，只是把旧文件再堆到一个新地方。

文件先留在原地

制度在网盘，项目在在线文档，合同在另一个盘。先让人能问到这几个地方，不要宣布从下周起全部迁到新库。迁移通常停在一半，大家不知道该信哪边。

第一批只收员工真的会找的：员工手册、报销、休假、账号申请、常用流程。十年的文件一上来都做进索引，搜出来的多半是过期版。

权限沿用原来的地方

知识库最容易出事的一种是：原文件夹只有财务能打开，搜一下全公司都能看见。谁在原处打不开，谁在这里也不该看见。

接上之后，用一个普通员工的账号试。工资、未公开的合同、客户名单，搜出来应当是空的。用管理员账号试，什么都能看见，那次试过了也没用。

用十个问题验收，不要用文件名验收

问「年假怎么请」，不要问「员工手册 v3」。答不上来，就补一页说明，或把标题改成这句话。再买一个库，不会凭空生出这页说明。

每条答案旁边要能打开原文的那一页。没有出处的答案，错一次之后就没人再信。

常用文档要有一个还在的人负责

离职的人留下的文档，别人不敢改，也不敢删。常用的那几十份写上谁负责、哪一天对过内容。没有人认领的，不要放进新人必读。

搭建完成的标志不是「系统上线了」。标志是那十个问题，普通员工都能问到，并且点得开原文。
