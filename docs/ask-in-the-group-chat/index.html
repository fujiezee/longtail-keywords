公司文件找不到，总在群里问怎么办

找一个文件要在群里问一圈，通常不是员工不会搜。文件在网盘、在线文档和聊天记录里各有一份，标题是作者随手起的，旧版还在群里传。先改这三件，再谈要不要上新系统。

标题改成他会问的那句话

「终版」「最新」「张三整理」搜不到。「年假怎么请」「报销要哪三张单」才搜得到。同一件事只留一个链接。旧链接打开后跳到这一份，两份不要同时算数。

常用的收成一个入口

群文件、个人网盘、某个人的收藏，都不是公司资料。请假、报销、领设备、开账号，按要办的事放在新人进门就看得见的地方。不要按部门架构分。架构是写给编制的，员工要找的是「我明天出差，标准是什么」。

用原话试，不要用文件名试

问「年假怎么请」，不要问「员工手册 v3」。问不出答案，就补一页，或把标题改成这句话。用一个刚入职的账号走一遍。走不通的那一步就是缺口。

答案旁边要能打开原文。没有出处的，错一次之后就没人再信。不该看的文件，比如工资和未公开合同，用普通员工账号搜出来必须是空的。

逐步做法见 员工找不到公司资料怎么办。
