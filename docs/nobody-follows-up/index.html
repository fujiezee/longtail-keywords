报了的问题没人跟进怎么办

质量问题提了过几天没人跟，异常订单在群里一刷就没了，隐患报上去整改停在半路。群消息不是跟踪。没有负责人、没有「哪天前要有结果」，这件事报完就结束了。

报的时候就写上人和日期

谁接、哪一天前要有个说法。缺一个，就不要算「已经报了」。质量、订单异常、安全隐患都可以是这同一行：编号、负责人、截止日期、现在的状态。

超时继续出现在他要看的地方

过了日期还是开着的，每天仍出现在负责人面前，越拖越麻烦的排在前面。发过一次就算提醒完，和没报一样。状态变成处理完、关闭、或明确不处理，才从列表里消失。

处理的时候能看见规定

催人去办，还要让他点得开「这件事按规定怎么处理」。没有依据的催促，会催出口头答应，留不下记录。办完记下谁在什么时候选了哪个结果。

逐步做法见 跨部门事项不靠人催也能推进。
