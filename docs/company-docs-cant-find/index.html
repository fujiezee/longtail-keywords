公司文档太多找不到怎么办

公司文档太多找不到，先别再买一个盘。同一份制度在网盘、聊天记录和个人电脑里各有一版，名字叫「终版」「最新」「张三整理」。人搜的是事情，不是文件名。

先收常用的几十份

请假、报销、领设备、开账号、员工手册、报销附件要求。十年的档案先不要全部做进搜索。全放进去，排在前面的经常是过期版。

标题改成会问的那句

「年假怎么请」「报销要哪三张单」。同一件事只留一个链接。旧文件打开后跳到这一份，不要两份同时算数。

用新人的账号试一次

问「年假怎么请」，不要问「员工手册 v3」。问不出，就改标题或补一页。工资、未公开合同，用普通员工账号搜出来应当是空的。
