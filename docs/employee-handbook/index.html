员工手册最新版在哪

员工手册最新版应当只有一个地址。群里转发的 pdf、某人桌面上的「手册终版」、网盘里的 v3 和 v7，会同时被当成真的。问的人要的是现在还生效的那一版。

固定一个链接

入职通知、公告、新人必读，都放这一个链接。旧文件不要删了就没下文，打开后跳到这一份。文件名可以改，链接不要换。

写上生效日期和替换了什么

封面或第一页写清从哪一天起用，以及这次改了年假、考勤还是报销。没写日期的「最新版」，三个月后就没人敢信。

按问题能翻到那一节

员工不会搜「第三章第二节」。他们问年假、加班、离职证明。目录用这些话。某一节改了，不要只在群里说「看新手册」，指出改的是哪一节。

找不到最新版时的做法见 员工找不到公司资料怎么办。
