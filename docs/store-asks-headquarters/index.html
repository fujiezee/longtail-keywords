门店天天问总部同样的问题怎么办

门店天天问总部同一件事：这件能不能退、这个位置怎么陈列、这个促销今天还算不算。总部的人变成了客服。规则其实在方案和手册里，门店没有、或有一份过期的。

用门店的句子当标题

「顾客无小票能退吗」「端架陈列几件」「满减和会员价能不能叠」。不要用「2026 年门店营运手册第三章」。每句一个短答案，链到当前生效的那一页。活动换了，旧链接跳到新页。

促销和合同单独记到期日

促销结束、供货合同到期，忘了就是损失或断货。一行一个活动或合同：名称、区域负责人、结束日。结束前几天推给区域经理，不要等门店先问「这个活动是不是已经停了」。

新店员不要靠老人带完才上岗

老人一走，门店又开始问总部。第一周的问题收成一页，新人自己问得出。问不出的那句，才是总部该补的文档，不是该再回答一遍的电话。
