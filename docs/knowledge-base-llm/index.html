内部知识库怎么接大模型

内部知识库接大模型，顺序是：先按这个人的权限取出相关原文，再把这些原文交给模型组织答案，答案旁边链回那一页。把整库直接丢给模型、不检索，它会用训练里见过的泛泛说法来答本公司的制度。

检索不到就停

没有匹配的段落，就说没有找到，或指出该问谁。不要让模型「根据一般做法」补全。公司制度往往和一般做法不一样，补出来的那句无法核对。

原文要比模型的话先出现

员工要能点开制度或记录的原页。只给一段改写、没有链接，错了也无法对。知识库里过期版和现行版同时在，检索会把旧的送上去。现行版只留一份。

换模型不必重做库

文档、权限、那十个验收问题是资产。模型可以换。先换模型、文档还是空的，接上了也还是空的。
