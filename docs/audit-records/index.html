迎检前材料怎么一次找齐

迎检前到处要材料，是因为记录平时没有按「这一份东西、谁处理的、什么时候处理的」留下。检查方问的是某一台仪器、某一份样本、某一位客户，不是「质量部文件夹」。

平时就按编号记结果

样本、仪器、合同、证件，每一条在到期或办完时留下结果：办了、延期了、停了，以及是谁点的。只在检查前补写，时间对不上，记录也站不住。

问法用检查方的原话

「S-0412 是怎么处理的」「这台仪器上次校准是谁做的」「这个客户的证件什么时候更新的」。问得出、并且能打开当时的记录和规定，才算找齐。问文件名，检查方并不这么问。

规定和记录放在能一起问的地方

规定说延期要批准，记录却在另一张没人看的表里，两边对不上。把规定原文和这条记录留在同一处可查。缺的那一页在检查前补不上，就提前标出来，不要临时编。
