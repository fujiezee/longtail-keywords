实验室样本保存期超了怎么办

样本过了保存期才发现，检测结果往往不能用，只能重新取样。客户或审核问起某一份，还要翻好几天。到期日如果在某个人的表里，他不在，就没人知道今天有哪几份要处理。

一份样本一行

样本编号、负责人邮箱、保存到期日。没有这三列的，先补表，不要先上系统。提前几天提醒按你们的 SOP 定，常见是到期前 2 到 3 天。填 0 的话，过了期限才有人看见，样本可能已经不能用了。

管理员当天只做三选一

已处理：检测完或转存了，这条关闭。申请延期：样本还能用，记下已申请。报废：不能用了，记下报废。状态一变就不要再提醒。三个以外的说法，回头对不上记录。

审核时问编号，不要问文件夹

「S-0412 是怎么处理的」「保存 SOP 对延期怎么规定」。两个都能打开原文，这份样本才算有记录。试剂有效期、质控重测可以用同一套：一行一个编号，一个负责人，一个日期。
