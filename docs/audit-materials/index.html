迎审材料怎么准备

迎审材料怎么准备，按检查方会点名的东西来收，不要按部门文件夹来收。他们问某一台仪器上次校准、某一份样本怎么处置、某一份合同谁批的。临时从微信里导出，时间和签字对不上。

先要一份问题清单

把上次检查问过的、这次通知里点名的，写成问句。每一问旁边是记录在哪、规定在哪。缺的那一页提前标出来，不要检查当天现写。

记录要有人和时间

谁做的、什么时候做的、结果是通过、延期还是停用。只有一份扫面件、没有这些，材料在，账对不齐。

规定和记录能一起打开

规定说延期要批准，批准却在另一张没人看的表里。检查时两头都要打得开。现行有效的制度用固定链接，不要把作废版打进包里。
