What is the difference between a knowledge base and a shared drive?

A shared drive stores files in folders. Someone has to know which folder to open. A knowledge base answers a question: “how does annual leave work?” returns the sentences in the handbook and links the file. The files can stay on the drive. A knowledge base is retrieval and answers, not a second drive to buy.

The drive stores. The knowledge base answers.

Permissions still come from the drive. A folder they cannot open there must not be searchable. Copying files into a new library often widens who can see them.

When answers are not enough

Q&A only covers what was written down. Contract and certificate dates still need someone watching them. A date in a file does not mean anyone sees it before it lapses.
