The knowledge base was updated and AI still quotes the old version

The answer is not using the file you just edited. It is using the copy from the last export or sync. When both versions stay searchable, it states the old clause with confidence.

Edit and read the same place

People edit in the docs suite, the drive, or the system you already have. If Q&A reads a saved copy somewhere else, the edit does not show up. Connect the original, and read that page again after it changes.

Take the old file out of search

Remove obsolete files from the index. Adding “old” to the title is not enough. Ask the leave question again. The source should be the updated page. If the sentence there does not match, the update is not done.
