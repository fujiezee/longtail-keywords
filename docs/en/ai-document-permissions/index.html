Will AI show files an employee should not see?

It must not. If they cannot open a file on the drive or in the docs system, the answer must not include its title, a summary, or a quote. If it does, the knowledge base is less safe than the folder it came from.

Use the source permissions

Do not keep a second list that marks everything as readable. A folder limited to finance, legal, or a manager stays limited at retrieval. When sharing changes, the index has to follow. The first sync is not enough.

Search sensitive words as a normal employee

From an account with no extra rights, search for pay, unreleased contracts, and customer lists. Any hit means you turn off company-wide access and find which sync widened the rights. An admin login sees everything, so it is not this test.

Missing and forbidden look the same to the asker

No document: say nothing matched. The document exists but this person cannot read it: do not hint that it exists. Both should read as “nothing you may see.” A different message leaks the file name.
