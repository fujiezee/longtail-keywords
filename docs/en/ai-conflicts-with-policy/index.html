What if the AI answer disagrees with company policy?

Open the source it cited. The mismatch is usually an old copy, or there is no source and the model filled the gap. A prompt that says “follow company policy” does not fix it. The model does not know which version counts.

Only the current version stays searchable

After a policy change, take the old file out of retrieval, or mark it obsolete and stop indexing it. Two leave-policy files on the same question get blended into one answer.

No match means no answer

If the current policy was not retrieved, the reply is that nothing was found, not a general rule from training. The person must be able to open the page and see the sentence.
