AI answers with no source, and it makes things up

An answer with no source is a guess. Stop the guess: if this person has no matching page they may read, do not answer. If there is a page, every statement opens that file.

Ask which page it used

Ask something in your own rules, such as how many days of leave, or which receipts a claim needs. If the answer matches a page, link that page. If it matches nothing, throw the answer out. A stricter prompt does not fix a missing document.

Say when nothing was found

“Industry practice is usually…” is not usable inside a company. When your rule differs, that sentence is fiction. The empty answer is: nothing you may read matches, or here is who to ask.

Keep a single current copy

An old handbook still in the index gets quoted with confidence. That is also a false answer: the sentence is from a file, and the file is obsolete. Old links should open the current page.
