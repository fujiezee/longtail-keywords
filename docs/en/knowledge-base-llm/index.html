Connect an internal knowledge base to a large language model

Connect them in this order: retrieve the passages this person is allowed to read, then let the model phrase an answer from those passages, with a link to the page. If you hand the model the whole library and skip retrieval, it answers your policy with something it saw in training.

Stop when retrieval is empty

If nothing matches, say so, or name who to ask. Do not let the model fill in “standard practice.” Your rule is often different, and the invented line cannot be checked.

The source page comes with the sentence

People need to open the policy or the record. A paraphrase with no link cannot be disputed. If the expired copy and the current copy are both indexed, the old one will surface. Keep one current copy.

You can change the model later

The documents, the permissions, and the ten test questions are the asset. The model can be replaced. Replacing the model while the library is empty leaves the connection empty.
