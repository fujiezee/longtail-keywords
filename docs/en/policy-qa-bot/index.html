How to build a company policy Q&A bot

Connect the current handbook and policies. Test with the words employees actually use. Every answer links the clause. The bot does not memorize policy. It looks up the page each time.

Ten questions before the full text

Leave, expenses, overtime, probation, offboarding. When those ten open the current clause, widen the set. A long policy titled with a file name will miss “how does annual leave work?” Put the question in a title or the opening lines that get indexed.

Design the cases it must refuse

If no clause matches, say so and point them to the owner. Pay details and unpublished disciplinary files stay hidden when the person cannot open them in the source.
