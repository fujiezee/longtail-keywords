仪器校准过期了还能用吗

仪器校准过期了还能用吗：要拿它的数做检测、放行或校准链上的记录，不要继续用。过期期间已经出具的结果，要按你们的质量规定单独评估。只用来看个大概、规程允许限用的，也要标明限用，不能和在校准期内的仪器放在一起不加区分。

先停，再决定送还是退

贴上停用或隔离。然后三选一：已送检、已校准、停用。送出去了还没出证书，不能写成已校准。三个结果都要有日期和谁确认的。

到期前就要排上

外部实验室要预约。提前 7 天提醒负责人，通常才来得及。当天发现过期，这台只能停，已经排上的检测要改期。

一台一行

仪器编号、负责人、校准有效期。保养到期是另一列，不要和校准写在同一个日期格里。审核问的是某一台上次谁校准的，不是质量部文件夹。
