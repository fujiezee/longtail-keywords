新员工入职老是问同样的问题怎么办

同一个问题，新人问了十遍，老员工答了十遍。问题多半已经写在手册、制度和流程里，只是新人不知道文件叫什么、放在哪。把第一周真的被问到的句子收下来，比再写一本厚手册有用。

先记下原话

入职第一周，群里和当面被问到的，原句留下。「门禁怎么开」「报销贴哪张」「电脑坏了找谁」。不要改成「行政管理制度」。外面的人就是用原句在问，书面标题对不上。

给一个先看的入口

这十几句放在一起，标成新人先看。每句下面是短答案，旁边是原文链接。没有文档的那句，写上该找谁，不要留白，也不要编一个答案。

老人不再当搜索引擎

第二次有人问同一句，把链接丢回去，不要重新讲。讲过的若和文档不一致，改文档，不要改口口相传的版本。人一请假，口传的那版就停了。
