员工找不到公司资料怎么办

员工找不到公司资料，通常不是他不会搜。资料在三个地方，名字是作者随手起的，旧版还在群里传。先改这三件，再谈要不要换工具。

标题改成他会说的那句话

「终版」「最新」「张三整理」都搜不到。「年假怎么请」「报销要哪三张单」才搜得到。同一件事只留一个链接。旧链接打开之后跳到这一份，两份不要同时算数。

收成一个新人进门就看得见的入口

群文件、个人网盘、某个人的收藏夹，都不是公司资料。常用的放进一个入口，按要办的事来分：请假、报销、领设备、开账号。不要按部门架构来分。架构是写给编制的，员工要找的是「我明天出差，标准是什么」。

权限不要靠口头告诉他去问谁

「这个问小王，他有权限」的结果是：没有权限的人永远找不到，小王请假这件事就停了。该看的人在原处就有权限。不该看的人，搜也搜不到。

用一个刚入职的账号走一遍请假、报销、领设备。走不通的那一步，就是资料缺口，不是员工的问题。

人走了，答案还在不在

只活在某人电脑或聊天记录里的，离职当天就没了。交接时要交的不是「文件夹已移交」，而是十个常见问题各自的链接。接的人用自己的账号点得开，才算交完。
