企业知识库怎么搭建

企业知识库怎么搭建，先写三件事：文件现在在哪，谁可以看，新人第一周会问哪十个问题。这三件没写下来就换系统，只是把旧文件再堆到一个新地方。

文件留在原地

制度在网盘，项目在在线文档，合同在另一个盘。先让人能问到这几个地方。宣布下周全部迁完，迁移通常停在一半，大家不知道该信哪边。

权限沿用原来的地方

原文件夹只有财务能开的，搜一下不该全公司都能看见。用普通员工账号试。管理员账号什么都看得见，那次试过了也没用。

用十个问题验收

问「年假怎么请」，答不上来就补说明。每条答案要能打开原文。没有出处的答案，错一次就没人再信。常用文档写上谁负责。没人认领的，不要放进新人必读。
