长尾词和关键词有什么区别

关键词是主题，长尾词是这个主题下一个人会原样打进搜索框的那句话。

「知识库」是关键词。它太大：有人想买软件，有人想找一份制度，有人想看开源项目。搜索结果只能猜。「新员工入职找不到员工手册」是长尾词。意图就一件事，现在就要找到那份文件。

竞争不一样

大词前面是门户、大公司和广告。长尾词前面常常还没有一篇专门回答它的文章。你写的那一页若真的答完了这句话，就有机会排在那些栏目页前面，因为栏目页并没有回答它。

意图不一样

从大词看不出对方要买、要学，还是要找一份文件。长尾词把意图写在字面上。带「多少钱」的是在比价，带「怎么办」的是卡在一件事上，带「和什么的区别」的是已经有两个候选，要帮他选。

所以「长尾词和核心词哪个好」本身也是一句长尾。答案取决于你要占住主题，还是要接住一个具体的人。主题用核心词做栏目，具体的人用长尾词做单页。

一页能不能答完

大词需要一个栏目才撑得住。长尾词用一页就能答完：先给结论，再给做法。硬把长尾词写成综述，读者要的那一句会被埋进目录里。

怎么判断你写下的是哪一种

把标题读出来。像目录名，例如「知识库指南」，它是关键词。像同事在问你，例如「制度改了，旧版还在群里传，怎么办」，它是长尾词。

写作时先收下原话，再把原话归到某个主题下面。顺序反了，写出来的都是栏目。
